Cấu hình GitHub (Vercel Sync)

Vì Vercel chạy môi trường Serverless chỉ đọc, khi bạn tải ảnh lên hoặc xóa ảnh, hệ thống sẽ tạo commit trực tiếp lên GitHub repository để lưu trữ vĩnh viễn và tự động kích hoạt cập nhật.

Mã Token cá nhân được lưu bảo mật trong trình duyệt của bạn (hoặc bạn có thể cấu hình biến GITHUB_TOKEN trong Vercel Settings).
Cách lấy GitHub Token:
  1. Đăng nhập GitHub > vào Settings > Developer Settings.
  2. Chọn Personal access tokens > Tokens (classic).
  3. Bấm Generate new token, đặt tên (ví dụ: fme-ctut) và tích chọn quyền repo.
  4. Sao chép mã token dán vào ô trên và bấm Lưu Token.
